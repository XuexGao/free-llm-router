/*
 * ⚠️ 全局防御：`[hidden]` 必须压过任何作者样式的 `display`。
 *
 * 根因（线上实测）：`.banner { display: flex }` 的优先级**高于**浏览器默认的
 * `[hidden] { display: none }`（作者样式 > UA 样式），于是 `hidden` 属性

 * 点「立即解除」也没用（不报错，只是不生效）。

 * 这里用 `!important` 一劳永逸：**任何**元素只要带 `hidden` 就一定不显示，
